# Linux – Documentation technique

Cette section regroupe des notes techniques et des ressources pratiques consacrées à Linux, à son administration et à son exploitation dans un environnement de développement et de production.

L'objectif est de consolider les connaissances nécessaires pour comprendre le fonctionnement d'un système Linux, administrer un serveur, diagnostiquer des incidents et collaborer efficacement avec les équipes de développement et d'exploitation.

## Parcours d'apprentissage recommandé

Pour progresser de manière structurée, voici un ordre d'étude conseillé :

1. **Fondamentaux** : comprendre l'architecture Linux et maîtriser la navigation dans le système de fichiers.
2. **Administration** : apprendre à gérer les utilisateurs, les permissions, les processus et les services.
3. **Réseau** : comprendre les communications réseau, le DNS et les connexions SSH.
4. **Automatisation** : maîtriser les variables d'environnement et les scripts Bash.
5. **Exploitation et sécurité** : savoir analyser les logs, diagnostiquer les incidents et appliquer les bonnes pratiques de sécurité.
