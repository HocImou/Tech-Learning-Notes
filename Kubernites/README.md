# Parcours Kubernetes — API Spring Boot fictive

Ce dossier rassemble les notions étudiées avec une application fil rouge fictive nommée `api-commandes`. Aucun nom d'application réelle n'est utilisé.

## Documents

1. **[Partie 1 — Fondations Kubernetes](guide-kubernetes-partie-1-fondations.md)**  
   Rôle de Kubernetes, architecture du cluster, control plane, nodes, familles de ressources, modèle déclaratif, manifests YAML, Namespace, Pod, cycle de vie et première vue d'ensemble de l'API.

2. **[Partie 2 — Ressources et relations](guide-kubernetes-partie-2-ressources-et-relations.md)**  
   Deployment, ReplicaSet, Pods, labels/selectors, Services, ports, endpoints/EndpointSlices, ConfigMap, CRD/Operators, RBAC, StatefulSet, commandes et diagnostic.

## Progression pédagogique

- **Partie 1 :** comprendre les fondations et le vocabulaire.
- **Partie 2 :** comprendre comment les objets Kubernetes collaborent.
- **Étapes suivantes :** probes, ressources CPU/mémoire, Ingress en profondeur, Secrets et External Secrets, stockage, HPA, PDB, NetworkPolicy, Helm et GitOps avec Argo CD.

Les étapes suivantes sont un programme de progression ; elles ne sont pas présentées comme des sujets déjà entièrement étudiés.
